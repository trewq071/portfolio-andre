# Portfólio — André Simões

Site pessoal de uma página, feito com HTML, CSS e JavaScript puros.

## Como abrir

1. Extraia o ZIP sem alterar a estrutura dos arquivos.
2. Abra `index.html` no navegador (duplo clique).
3. Navegue pelas seções e use os botões para visualizar ou baixar `assets/curriculo.pdf`.

Não precisa instalar nada, iniciar servidor ou criar banco de dados.

## Organização

- `index.html` — conteúdo e estrutura da página.
- `style.css` — aparência e responsividade.
- `script.js` — menu no celular e ano automático no rodapé.
- `assets/curriculo.pdf` — versão pública do currículo, sem endereço completo, telefone pessoal e data de nascimento.

## Informações do currículo

Nome, formação, resumo profissional, conhecimentos em informática, competências administrativas e do curso TADS, inglês, objetivo de estágio, disponibilidade diurna e e-mail.

O currículo não informa projetos realizados, experiências profissionais anteriores, cursos/certificações adicionais nem perfis GitHub ou LinkedIn. Por isso, nenhum foi inventado e não há placeholders.

**Privacidade:** o PDF disponibilizado no site é uma versão pública e resumida, produzida com dados do documento enviado. O documento original enviado possui dados pessoais que não foram incluídos nessa versão pública.
